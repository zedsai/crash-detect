# CRASHSCOPE

Dark-theme dashboard comparing the 1929 crash, the 2000 dot-com bust, the 2008 financial crisis, and the current market.

Includes labor and equity indicators, a recession-probability model, an Anthropic/OpenAI IPO volatility scenario, and money-allocation recommendations. Current readings are sourced from FRED, BLS, Shiller/Multpl, the NY Fed, OECD, and BEA, with a live refresh path and a verified snapshot fallback.

## Run locally

```bash
npm install
npm run dev
```

Open the printed localhost URL (Vite default is `http://localhost:5173`).

```bash
npm run build
```

Educational tool only. Not financial advice.
